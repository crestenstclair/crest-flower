The device is a MIDI generator, so place it before an instrument. It reads Live’s Set scale automatically and takes over the Push matrix while its track is selected.

01

Build the chain

Place Push Chord Grid before Drift, Wavetable, a Rack, or any other Standalone-compatible instrument.

02

Set Live’s scale

Choose the root and scale in Live. The grid follows those Set values; there is no duplicate key selector.

03

Select the track

Track focus acquires the 8×8 matrix and paints its roles. Moving focus away safely releases notes and LEDs. If a hardware power cycle leaves the grid dark, click Reload Grid on the device.

Current usage

Play harmony.
Shape the next hit.

The surface separates harmonic choice from voicing. The current-state line begins with the detected Live scale, so a key change such as C Major → C Minor is immediately visible. Chord and extension controls are momentary; Voice, Nearest, and bass settings persist. A sounding chord never changes behind your back.

AUTO HARMONY

A minor means A · B · C · D · E · F · G · A

The device stacks scale degrees 1/3/5 from each root, producing the correct triad for the selected Live scale.

PAD VELOCITY

Your strike shapes the whole chord

Every playable pad on ranks 1–4 is velocity-sensitive. Its physical strike velocity is copied to every newly sounding note in the generated chord, from a soft touch through a full hit.

QUALITY OVERRIDE

Hold a type, then hit a chord

Dim, Min, Maj, and Sus temporarily replace automatic quality. Release the control to return to scale-derived harmony. The control itself emits no MIDI note.

6 · m7 · M7 · 9

Extensions are additive—and combinable

Hold one or more extension pads before striking a chord. Each adds its own root-relative tone: +9, +10, +11, or +14 semitones.

VOICE

Move through inversions without changing the chord

Voice + repeatedly moves the lowest chord tone up an octave. Voice − moves the highest down. Voice 0 returns future chords to root position.

NEAREST · D7

Let progressions choose their smoothest inversion

Tap D7 to toggle Nearest. The first chord establishes history; later chords choose the closest inversion within one rotation of that pad’s row and Voice baseline. Bass never steers the choice. Changing Voice, Live’s scale, Base Octave, Nearest mode, or lifecycle focus clears history so the next chord starts from a clean baseline.

BASS

Add a root voice in its own register

Bass toggles the extra root on or off. Bass − and + move it by octaves; Bass −1 resets it to one octave beneath the chord root.

SAFE HOLDS

Pressed notes are snapshots

Modifiers, scale changes, and voicing changes affect future presses only. Focus loss, disable, Reload Grid, deletion, and Set close release every active note plus CC123.

RECOVERY

Reload the grid without reloading the Set

Re-enabling the device automatically rediscovers Push. If the hardware was power-cycled and the matrix stays dark, click Reload Grid: it safely releases stale ownership, rediscovers the matrix, reacquires it, and repaints every pad.

EXACT FEEDBACK

See what the device actually emitted

The device face separately shows current controls and the last chord’s name, resolved quality/extensions, manual or Nearest inversion, and every emitted note name with its MIDI number.

Dedicated device line

Explicitly outside this device

No embedded Strum or Arp

Strumming and arpeggiation are intentionally delegated to Ableton MIDI devices. That keeps this device’s note ownership deterministic and lets Live handle tempo-synced event generation where it already excels.

Live already owns this

Sound, sequencing, and arrangement

Synth engines, effects, drums, BPM, looping, overdub, Capture MIDI, and clip arrangement stay native to Live. Other timed Orchid-style modes—Slop, Pattern, and Harp—are not proposed unless the downstream Ableton workflow reveals a real missing capability.
